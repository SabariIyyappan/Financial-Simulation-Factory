API Version 2.0 - Breaking Changes

⚠️ Breaking Changes in V2

The Pricing API has been updated to version 2.0 with breaking schema changes. Please update your integration code accordingly.

Schema Changes

price → pricing.amount
currency → pricing.currency

Migration Guidance

The price and currency fields have been moved into a nested pricing object for better organization and future extensibility.

Old V1 Response:

{
  "product_id": "sku-123",
  "price": 129.99,
  "currency": "USD",
  "api_version": "v1"
}

New V2 Response:

{
  "product_id": "sku-123",
  "pricing": {
    "amount": 129.99,
    "currency": "USD"
  },
  "api_version": "v2"
}

Action Required

  • Update your client code to access pricing.amount instead of price
  • Update your client code to access pricing.currency instead of currency
  • Test your integration thoroughly before deploying to production
  • V1 will be deprecated on December 31, 2024
